## 🙋 ตอบคำถามที่เจอบ่อย

**Q: ต้องเขียนโค้ดเป็นไหม**
ไม่ต้องเลยค่ะ แค่เปลี่ยนรูปกับพิมพ์ข้อความ ทำบนเว็บได้ทั้งหมด ไม่ต้องลงโปรแกรม 😊

**Q: เสียเงินเพิ่มไหม**
ไม่เสียค่ะ GitHub กับ Vercel มีแพ็กเกจฟรีสำหรับใช้งานส่วนตัว ทำเป็นของขวัญให้แฟนใช้ได้เลยค่ะ

**Q: ทำบนมือถืออย่างเดียวได้ไหม**
แนะนำให้ใช้คอมหรือ iPad ค่ะ เพราะต้องลากไฟล์ขึ้น GitHub ส่วนแฟนเปิดเล่นบนมือถือได้ปกติ

**Q: ลากไฟล์ขึ้น GitHub แล้ว Deploy ไม่ผ่าน**
ลองเช็กว่าลาก "ของข้างในโฟลเดอร์" ไม่ใช่ลากตัวโฟลเดอร์ทั้งก้อนนะคะ ในหน้า repo ต้องเห็นไฟล์ `package.json` อยู่ชั้นแรกเลย

**Q: แก้ข้อความแล้ว Deploy ไม่ผ่าน (Error)**
น่าจะเผลอลบเครื่องหมาย `"` หรือ `,` หรือ `}` ไปค่ะ แคปหน้าจอไฟล์ `birthday.ts` ตรงที่แก้ส่งมาได้เลย เดี๋ยวช่วยดูให้ค่ะ

**Q: รูปไม่ขึ้น**
เช็กชื่อไฟล์ให้ตรงเป๊ะ (`portrait.jpg`, `memory-01.jpg` …) และต้องเป็น `.jpg` ตัวพิมพ์เล็กค่ะ ถ้าเป็นไฟล์ .HEIC จาก iPhone ให้ส่งรูปเข้าแชท LINE ตัวเองแล้วเซฟใหม่ จะได้เป็น .jpg ค่ะ

**Q: อยากใส่มากกว่า 3 รูป / ใส่คลิป**
ได้ค่ะ ดูวิธีใน `README.md` หัวข้อ "ปรับแต่งเพิ่ม" ส่วนคลิปให้ตั้งชื่อ `memory-video.mp4` แล้วอัปเข้าโฟลเดอร์เดียวกับรูปได้เลยค่ะ

**Q: แก้ข้อความหลังส่งลิงก์ไปแล้วได้ไหม**
ได้ค่ะ แก้ใน GitHub แล้วกด Commit เว็บจะอัปเดตเองใน 1–2 นาที ลิงก์เดิมใช้ได้ต่อค่ะ

**Q: แฟนเปิดแล้วตั๋วหาย / เล่นใหม่ตั้งแต่ต้น**
ตั๋วจะบันทึกไว้ในเบราว์เซอร์ของเครื่องที่เปิดค่ะ ให้แฟนเปิดลิงก์จากเครื่องเดิมและแอปเดิมทุกครั้ง (ถ้าเปิดในโหมดไม่ระบุตัวตน ข้อมูลจะไม่ถูกเก็บค่ะ)

**Q: แฟนเป็นผู้หญิง / อยากเปลี่ยนสี**
ข้อความทั้งหมดแก้ได้ตามต้องการค่ะ ส่วนสีเปลี่ยนได้ในหัวข้อ `theme` ใน `README.md` มีตัวอย่างโทนฟ้าให้ด้วยค่ะ
