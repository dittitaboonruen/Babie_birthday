## 🔗 ทำลิงก์เว็บตัวอย่าง (ไม่บังคับ)

1. ทำตาม `START-HERE.md` ใน ZIP ด้วยตัวเอง 1 รอบ ถือเป็นการซ้อมก่อนอัดคลิปสอนไปด้วย
2. ไม่ต้องเปลี่ยนรูป ให้ใช้รูปหัวใจตัวอย่างได้เลย
3. ใส่จดหมายตัวอย่างนี้ใน `birthdayLetter.th` จะได้ดูสวยตอนลูกค้าเปิดจดหมาย

```ts
th: `สุขสันต์วันเกิดนะคนเก่ง 🎂

ขอบคุณที่อยู่ข้าง ๆ กันมาตลอด ขอให้ปีนี้เป็นปีที่ดีที่สุด
มีความสุขกับทุกอย่างที่ทำ และอย่าลืมว่ามีเราอยู่ตรงนี้เสมอ

(นี่คือตัวอย่างจดหมาย — ใส่ข้อความของคุณเองได้เลย ♡)`,
```

4. Deploy บน Vercel แล้วจะได้ลิงก์ เช่น `lovequest-demo.vercel.app`

⚠️ แพ็กเกจฟรีของ Vercel (Hobby) ใช้ได้เฉพาะงานส่วนตัว ไม่ใช่เชิงพาณิชย์ เว็บตัวอย่างที่ใช้โปรโมตการขายจึงอาจผิดเงื่อนไข
ทางที่ปลอดภัยคือ **ใช้คลิป `demo-gameplay.mp4` แทนลิงก์** หรืออัปเป็นแพ็กเกจ Pro (ควรเช็กเงื่อนไขล่าสุดก่อน)
ส่วนลูกค้าที่ทำเว็บเป็นของขวัญให้แฟนเอง ถือเป็นการใช้ส่วนตัว ใช้แพ็กเกจฟรีได้

## 📦 ขั้นตอนส่งของ (เมื่อลูกค้าโอนแล้ว)

1. อัป ZIP ขึ้น Google Drive แล้วตั้งค่าเป็น "ทุกคนที่มีลิงก์ดูได้"
2. ก๊อปข้อความ "ส่งของ" จาก `customer-messages.md` ใส่ลิงก์ ZIP กับลิงก์คลิป แล้วส่งให้ลูกค้า
3. ลูกค้าติดตรงไหน ให้ใช้ข้อความตอบกลับสำเร็จรูปในไฟล์เดียวกัน
