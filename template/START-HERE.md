# 💗 LOVE QUEST: เริ่มตรงนี้

ทำเว็บเกมวันเกิดให้แฟนใน 4 ขั้น ใช้เวลาประมาณ 20 นาที ไม่ต้องเขียนโค้ด ไม่ต้องลงโปรแกรม ใช้ฟรี

**เตรียมไว้ก่อน:** รูป 4 รูป (`.jpg`), คำอวยพร, บัญชี GitHub และ Vercel (สมัครฟรี)

---

### 1️⃣ อัปโหลดไฟล์ขึ้น GitHub
1. แตกไฟล์ ZIP ที่ได้มา
2. เข้า **github.com** แล้วกด **New** เพื่อสร้างที่เก็บไฟล์ใหม่
   - ตั้งชื่อ เช่น `my-love-quest`
   - เลือก **Private**
   - กด **Create**
3. กด **uploading an existing file** แล้วลาก **ทุกอย่างที่อยู่ในโฟลเดอร์** ที่แตกไว้ไปวาง
4. กด **Commit changes**

### 2️⃣ เปลี่ยนรูป
1. ตั้งชื่อรูปของคุณ **ให้ตรงตามนี้**
   - `portrait.jpg` = รูปหน้าแรก
   - `memory-01.jpg`
   - `memory-02.jpg`
   - `memory-03.jpg`
2. ใน GitHub เปิดโฟลเดอร์ `public` → `memories` → กด **Add file → Upload files**
3. ลากรูปไปวาง แล้วกด **Commit changes**

### 3️⃣ ใส่ข้อความ
1. เปิดไฟล์ `src` → `config` → `birthday.ts` แล้วกด ✏️
2. แก้ **เฉพาะตัวหนังสือที่อยู่ใน " "** ตรงที่มีเครื่องหมาย ✏️ กำกับ (ชื่อ, วันเกิด, ข้อความใต้รูป, จดหมาย)
3. กด **Commit changes**

> ⚠️ อย่าลบเครื่องหมาย `"` `,` `{` `}`
> ✉️ จดหมายหลายบรรทัด ให้ครอบข้อความด้วย `` ` `` แทน `"`

### 4️⃣ เปิดเป็นเว็บ
1. เข้า **vercel.com** แล้ว login ด้วย GitHub
2. กด **Add New → Project** → **Import** `my-love-quest` → **Deploy**
3. รอ 1–2 นาที จะได้ลิงก์ 🎉 ส่งให้แฟนได้เลย

---

💡 อยากแก้อะไรเพิ่ม? แก้ใน GitHub แล้วกด Commit เว็บจะอัปเดตเองภายใน 1–2 นาที ลิงก์เดิมใช้ได้ต่อ
